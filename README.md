# Lucas Hansen — Psicólogo | Site institucional

Site institucional para um psicólogo com atendimento online, construído do zero em
**HTML, CSS e JavaScript puros** — sem frameworks, sem build step. Do briefing de
conteúdo e identidade visual até o deploy em produção.

🔗 **No ar:** [psicologolucashansen.com.br](https://psicologolucashansen.com.br/)

![Página inicial](https://github.com/Zelpheor/lucas-site/blob/3485c26660cb99b0472bf223d3c0e7ee7705dde3/img/Homepage.png)

## Destaques técnicos

- **Carrossel construído do zero** com `requestAnimationFrame` — deslizamento contínuo,
  scroll-snap nativo, pausa ao interagir (mouse/toque/teclado) e retomada automática
- **Menu com estado ativo dinâmico** via `IntersectionObserver`
- **Acordeão de FAQ acessível** (`aria-expanded`, navegável por teclado)
- **4 páginas** (home + 3 internas) com header/footer compartilhados e sub-navegação própria
- **Formulário de contato** integrado (Formspree)
- **100% responsivo**, mobile-first, sem bibliotecas de CSS
- `sitemap.xml` + meta tags por página (SEO básico)

## Stack

HTML5 semântico · CSS3 (custom properties, Grid, Flexbox, scroll-snap) · JavaScript (ES6+)
· Google Fonts · Font Awesome · Formspree
